# Archiver 8 export constructors

Archiver 8 is ESM and exposes the named `ZipArchive` constructor. The two
production export services use `new ZipArchive({ zlib: { level: 6 } })`.
The three fixture and transport helpers use the same constructor with their
existing compression levels: 6, 9 and 1.

The writer keeps its append, pipe, entry, warning, error, finalize and abort
handling. Backup exports retain their staged-file completion, read-only
snapshot, asset authorization and JSON/reference contracts. File exports retain
their access checks, filenames and streaming response behavior.

The repository's runtime floor is Node 22.12.0; Archiver 8 and its new runtime
dependencies declare Node 18 or newer. The matching `@types/archiver` 8
declarations are used directly.

The lockfile is generated by pnpm from the maintained package ranges. Other
dependency advisory records and broader archive/storage policy work remain
tracked separately.

The [8.0.0 release](https://github.com/archiverjs/node-archiver/releases/tag/8.0.0)
and its
[fixed-revision example](https://github.com/archiverjs/node-archiver/blob/52d1d349dfa2bf17956ecab56f477736688a9c5e/README.md)
describe the supported constructor.
