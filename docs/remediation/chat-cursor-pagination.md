# Chat history and thread cursor pagination

History pages order by `createdAt DESC, id DESC`; thread replies order by `createdAt ASC, id ASC`. The ID breaks equal-timestamp ties so a cursor can traverse those rows without omitting or repeating them. The web client still reverses history pages for display and keeps thread replies in their returned order. The existing default of 50 and maximum of 100 messages, one extra sentinel row, raw message-ID cursors and response shape remain unchanged.

A cursor must belong to the requested history channel's top-level messages, or to the requested thread's replies. A missing or unrelated cursor returns an empty page. A soft-deleted message remains a valid cursor and remains visible as the existing deleted placeholder. Normal channel/workspace/session authorization runs before the service; these scope checks do not replace it. Reply counts still include deleted replies, user/reaction fields remain, and client idempotency bookkeeping stays server-side.

The pinned Prisma engine emits SQL `LIMIT` for these two ordered cursor queries, so the database returns at most `limit + 1` message rows to the page query. This bounds returned message rows; it does not bound rows scanned or sorted, establish latency or memory capacity, or provide a snapshot across requests. Existing indexes, transaction/request budgets and message writers are unchanged. Concurrent writes can change later pages. Other chat cursor families and the wider P02a/R18 performance investigation remain separate.

The focused regression suite is `packages/backend/tests/integration/chat-cursor-pagination.test.mjs`; it uses disposable PostgreSQL fixtures, Fastify injected requests with live session-bound authorization and separately captured same-service generated SQL. It covers ordinary/tied traversal at limits 1, 2, 50 and 100, SQL sentinel bounds, cursor scope, deleted placeholders, reply counts and route limits/access. Run with a migrated disposable `TEST_DATABASE_URL` using the repository's integration-test command. Historical P02a measurements remain historical and are not reclassified as measurements of this change.
